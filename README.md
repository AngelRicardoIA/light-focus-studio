# Light Focus Studio

Portafolio de fotografía de Angel, fotógrafo en Guadalajara.

Un espacio para explorar mis fotografías, conocer los paquetes de sesión y consultar disponibilidad.

## El sitio

- Paquetes con precios y características.
- Galería con filtros y visor de fotografías.
- Presentación del fotógrafo.
- Información sobre el proceso y las condiciones de reserva.
- Preguntas frecuentes.
- Enlaces a WhatsApp e Instagram.
- Página de privacidad y uso de imagen.

Diseño adaptable a celulares, con tonos claros, superficies translúcidas y protagonismo de la fotografía.

## Tecnologías

HTML, CSS y JavaScript, sin frameworks ni dependencias de instalación.

## Uso local

Descarga el proyecto y abre `index.html` en tu navegador.

Mantén los archivos del sitio y la carpeta `assets` dentro del mismo directorio.

## Fotografías

Coloca las imágenes dentro de `assets` con estos nombres:

| Archivo | Uso |
| --- | --- |
| `Paquete_01.jpg` | Paquete Esencial |
| `Paquete_02.jpg` | Paquete Signature |
| `Paquete_03.jpg` | Paquete Historia |
| `Angel.jpg` | Retrato del fotógrafo |
| `IMG001.jpg` a `IMG006.jpg` | Galería |

Las fotografías de paquetes se muestran en formato vertical 4:5. El retrato del fotógrafo utiliza un formato cuadrado 1:1.

Para agregar más fotografías a la galería, incorpora los archivos en `assets` y registra sus entradas en `config.js`.

## Personalización

Edita `config.js` para actualizar:

- Datos de contacto y redes sociales.
- Precios y contenido de los paquetes.
- Imágenes, categorías y descripciones.
- Preguntas frecuentes.

El contenido general está en `index.html` y los estilos en `styles.css`.

## Privacidad

La publicación de fotografías de las sesiones requiere autorización de las personas retratadas.

Las solicitudes relacionadas con datos personales o retiro de imágenes pueden realizarse mediante el contacto indicado en `privacidad.html`.
